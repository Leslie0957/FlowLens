## H02 的失败究竟是什么

原始 `H02-wire-1.sse` 和 `H02-wire-2.sse` 都是 HTTP 200，结束原因为 `stop`。正文只有 `investigation`，叙述需要读取输出，但 `tool_calls` 为空。第二次请求带有具体 `REPAIR_RESPONSE_SCHEMA` 纠正提示，模型仍只返回调查说明。
