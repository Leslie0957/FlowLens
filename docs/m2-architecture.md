# M2 当前实现与边界

来源定位（2026-09-27 用户确认）：miniClaude 仅作为实现参考，FlowLens 的 Agent 底座为自行实现；产品流解析复用的是本项目 M0 探针代码，没有直接集成上游 Agent。后续阶段沿用此架构，保留来源和 MIT 许可说明。

## 数据与调用链

当前 schema 为 v4。v4 专门修复早期 v3 数据库仍保留 initial-only 模拟器约束的问题：事务重建 simulation_state 并保留所有进度，使旧库也能创建 retry。已应用迁移的数据库不能靠修改旧迁移代码升级。

SQLite v3 增量增加会话、轮次、消息、工具、证据、结果、事件、审批与执行记录；M1 run/log 保留。HTTP 创建消息后返回 202，后台执行 `runDiagnosis`。单会话最多一个活动 turn，应用最多两个。数据库保存事件序号和快照，SSE 按 after_seq 回放，前端 reducer 排除重复事件与其他会话事件。

`ModelGateway` 隔离 DeepSeek/MOCK；两者调用相同 `createTools` 和持久化逻辑。`TaskBackend`、`RunbookRetriever` 可注入，只提供当前任务读取和四篇允许文档的确定性检索。ToolRegistry 由可信服务端代码注册描述、严格 schema 和执行器，模型工具描述从同一 registry 取得；当前默认注册四个只读工具；未引入 Shell、文件修改、MCP 或任意 SQL 工具。最近六个已完成 turn 的问题、验证过的结论及有限证据进入同会话上下文，更早记录使用有界结论摘要。

模型结果执行结构校验、当前 session 证据校验和目标 run 校验；一次格式修复失败后明确失败。每轮上限 8 工具、12 模型请求；单次模型 45 秒、工具 5 秒、整轮 120 秒。暂时性模型错误最多重试一次，不回退 MOCK。结构化诊断统一使用共享严格 schema。

审批由服务端校验诊断与重试资格、有效期及运行快照。在同一事务中创建唯一 child、execution 和审批终态。S00/S05 不允许重试；S04 上游超时仅允许每个 parent 一个 child、恢复链最多两次。模拟器驱动 child 状态，批准不等于执行成功；原运行不改写。

## 页面与日志

运行详情包含诊断工作台、会话、消息、只读工具、结构化结论、证据抽屉及审批。Markdown 使用 Vue 文本节点渲染并限制链接协议。流式增量按字节解码，约 50ms/512 字符聚合落库。普通日志不输出逐 token 数据、完整问题、Prompt、工具内容或 Key；白名单关联 request/run/session/turn/tool ID。业务证据和审批事实保存在 SQLite，日志不替代审计。

## 明确未完成

- LIVE 仅通过服务层单轮诊断。真实上下文追问、浏览器至 DeepSeek 至审批完整链路未验收，6 次授权已全部消耗。
- ToolRegistry 已接入；全部响应运行时契约检查与适配器替换的完整矩阵仍待后续可靠性验证，不能称为已完成全部替换验收。
- 断线自动重连、取消晚到事件、重启中断恢复、复杂切换竞态和适配器替换矩阵按已确认计划在 M3 系统验证；当前仅有基本快照、取消和手动重连。
- LIVE 请求计数目前为进程内计数，重启会清零；配置上限不能视作跨重启费用账本。未经新授权不得借重启继续消耗额度。
- 本地单用户、实验性 node:sqlite、Chrome 与小规模 fixture 是当前验证边界，不包含公网鉴权或生产负载。
